Luna’s usage cost comes down to what goes in, what can be reused, and what comes back out. Here’s the short version—and a calculator to make it concrete.

Uncached input

New context Luna needs to read: your prompt, fresh files, and instructions. It’s billed at the standard input rate.

NEW CONTEXT
02↻

Cached input

Repeated context that can be reused, such as a stable system prompt. When cache pricing applies, these tokens cost less to process.

REUSED CONTEXT
03↗

Output tokens

The response Luna generates. Output is often priced separately from input, so a long answer can move the total quickly.

GENERATED TEXT
04⊣

Spend caps

A budget guardrail for a time period or workspace. A cap helps prevent runaway spend; check Luna’s settings to see whether it blocks, alerts, or pauses usage.
