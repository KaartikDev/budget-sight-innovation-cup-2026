How to read each signal

  1. Measured spend

    Sum of estimated turn costs in USD. Use it to compare activity in BudgetSight; it is an API-rate estimate, not a subscription invoice.

  2. Total tokens

    Recorded input plus output tokens. More tokens mean more context or generation; pair volume with outcomes and duration before judging efficiency.

  3. Prompt cache

    Cached input divided by all input. A higher rate can reduce eligible input cost when context repeats, but doesn’t tell you whether the work succeeded.

  4. Incomplete spend

    Spend tied to partially completed or failed turns. Check the affected turns and evidence; unknown outcomes are excluded because they signal missing confidence.

  5. Completed

    Count of turns classified as completed. Compare with all analyzed turns to understand the mix; a count alone is not a completion rate.

↗

Start with the relationship: if spend rises, check whether token volume also rose—and whether completed work rose with it. Treat a pattern as a prompt to review the underlying turns, not proof of waste.
