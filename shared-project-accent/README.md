## PaperPlane feature assignments

The [PaperPlane source snapshot](PaperPlane/LOCAL_SNAPSHOT.md) has five proposed features. Each is assigned below to a named regular user whose account exists in the local BudgetSight database. These are project ownership assignments recorded in this README; no BudgetSight task or GitHub issue was created.

| Feature | BudgetSight owner | Specific deliverable |
|---|---|---|
| OCR review before import | Maya Chen (`maya.chen`) | Let pilots edit or discard recognized rows before any flight entries are saved. |
| Rolling currency dashboard | Jordan Patel (`jordan.patel`) | Show dated activity windows, counted flights, and incomplete data on the pilot dashboard. |
| CSV import and export | Sofia Ramirez (`sofia.ramirez`) | Add a documented CSV format, a validated import preview, and user-scoped export. |
| Verification evidence and retry | Liam O'Connor (`liam.oconnor`) | Persist match results and reasons, invalidate stale results after edits, and support retry. |
| Search, filters, and saved views | Aisha Thompson (`aisha.thompson`) | Add server-side logbook filters, sorting, and per-user saved views. |

See [the detailed feature plan](PaperPlane/FEATURE_PROPOSALS.md) for behavior, acceptance criteria, and likely code areas.
